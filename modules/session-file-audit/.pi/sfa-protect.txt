# session-file-audit 保护清单
# ⚠️ 保护机制当前【默认关闭】：本文件内容不生效，除非设环境变量 SFA_GUARD=1 后重启 pi。
# 作用：命中的文件【永不被自动清理】（压缩前模型复核会直接跳过它们）。
# 语法：每行一条 glob，相对当前工作目录，用 / 分隔；** 匹配多层目录；
#       以 ! 开头 = 强制放行（优先级最高，可用来解除内置规则的保护）。
# 改完立即生效（无需重启）。

# —— 内置规则（不可删除，但可用 ! 放行）——
#   **/AGENTS.md 等  AGENTS.md / README.md / SKILL.md / 环境清单.md
#   **/*.pdf 等        用户文档成品（pdf/docx/xlsx/pptx）
#   **/*.py 等          脚本与配置数据（py/ps1/sh/js/ts/json/yaml/toml/ini/csv/db…）
#   项目目录               子目录内含 .git / README.md / package.json 等 → 整目录保护
#   会话前已存在           创建时间早于本会话开始的文件（长期文件、定时任务产出）
#     ↳ 例外：ws-* 会话工作区内的文件不受此条保护（ws-* 正是待清理范围）
# 注意：不再有 “ws-*/**” 这种整目录豁免——它会连会话自己的临时产物一起锁住，
#       使清理功能彻底失效。ws-* 里要保留的文件请在下面按类型/路径声明。
